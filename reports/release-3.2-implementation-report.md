Branch: `release-3.2-academic-teaching-integration` (from `origin/main` @ `e6348a4`) · Date: 2026-11-02

This is an incremental update. The design language, architecture (stdlib-only Python generator → static `site/`), navigation groups and editorial rules from Releases 1.x–2.1 are preserved. All content changes are in `data/*.json`, and the HTML is regenerated by `scripts/build.py`.

## 5. Multilingual architecture

**Findings.**
- English is the only published language. `locales/` contains only `en.json`.
- All other configured languages are marked `untranslated`, and no translated pages exist.
- The header switcher was a hard-coded list whose links all pointed to `languages.html`.
- `hreflang` lists only `en` and `x-default`, and the sitemap lists English URLs only. Both are **correct** while no translations exist.

**Changes.**
- The switcher is now generated from `data/languages.json`. Each entry carries `lang` and `dir` (Arabic, Persian and Hebrew get `dir="rtl"`) and links to that language's row on the Languages page. A visible note says "Translations are in preparation; English is the reference version."
- The Languages page now has an accessible availability table with plain-language statuses ("Planned — no translated pages yet") and a statement of translation principles: approved public content only; protected names, titles and codes; machine drafts labelled and human-reviewed; RTL layout.
- Portuguese (`pt`) and Chinese (`zh`) were added to match the intended coverage. **Persian (`fa`) and Hebrew (`he`) were already configured and were kept**. Remove them from `data/languages.json` if they are no longer intended.
- `translation_glossary.json`: 17 protected terms added (institution, programme, course and module names; conference acronyms; method names GASE, PTEB, HTEB and CRaFT). EU AI Act is marked to use each language's official EU name.
- No machine translations were produced. Untranslated English is never presented as a translation.

**Gap (not addressed in this release).** Full translation of the 56 pages into 12 languages is a separate piece of work that needs human review. The pipeline needs locale page generation, per-language `hreflang` alternates and sitemap entries, and RTL layout testing in a browser.

## 8. What happens on merge

Merging the PR into `main` triggers **Build and deploy**: validate → build → test → upload → deploy to the `github-pages` environment. The deploy takes about 1 minute. If any test fails, nothing is deployed and the current site stays live. To roll back, revert the merge commit on `main`; that redeploys the previous state (see `docs/rollback.md`).
